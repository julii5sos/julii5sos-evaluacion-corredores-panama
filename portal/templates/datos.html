Cómo funciona el motor

ejecutar_motor.py descarga de Earth Engine los insumos de la Cuenca del Canal + 10 km en una rejilla UTM de 30 m, calcula en Python las métricas FRAGSTATS, el ERI, la pérdida de conectividad, el riesgo y las prioridades, y deja GeoTIFF y capas para el visor en static/data/motor/.

La verificación de polígonos (/api/verificar) consulta Earth Engine en vivo para el polígono y el periodo elegidos. Sin Earth Engine usa los rásters que dejó el motor.

# Una vez
pip install -r requirements.txt earthengine-api
earthengine authenticate
set EE_PROJECT=tu-proyecto-no-comercial   # Mac/Linux: export

# Cada semana (alertas) o cada año (ERI)
python ejecutar_motor.py
# Portal con verificación en vivo
python app.py
